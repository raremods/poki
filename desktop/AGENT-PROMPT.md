Install Poki on my iPhone (or iPad). Poki is an app that lets AI agents see and use the phone. On a Mac with Node.js 24 or later, follow the install-poki skill at https://github.com/JosssphZhou/poki/blob/main/skills/install-poki/SKILL.md: it clones Poki and runs its installer, which uses the Qeno Setup on this computer. Without Node.js 24, or on Windows, use Qeno Setup's own command line tool, `poki-setup`, as described here. Either way, work through the steps yourself and only stop for what I must do by hand.

The tool
- macOS: "/Applications/Qeno Setup.app/Contents/MacOS/poki-setup"
- Windows: "$env:LOCALAPPDATA\Qeno Setup\poki-setup.exe"
If it is not there, ask me to install Qeno Setup from https://github.com/JosssphZhou/poki/releases (the Alpha release) and open it once. Below, `poki-setup` means that path, in quotes.

How to work
1. Run `poki-setup next --json`. It reads this computer's state and lists what is done and what is next. Each step has `who` ("agent" or "person"), `command` (run it as is) and `say` (tell me this, in your own words, when a person has to act). Do the first step that is not done, then run `next` again. Stop when `next` says Poki is ready.
2. Add `--json` to every command. Progress goes to stderr as one JSON object per line; the result goes to stdout. Exit codes: 0 done, 1 failed (read `error.message`, fix what it says, try once more), 2 a person has to act (tell me `error.message`, wait until I say I did it, then run the same command again), 3 waiting for the Apple sign-in code.
3. Apple sign-in needs my password, which must never go through chat. Ask me for my Apple Account email, then ask me to run this in my own terminal window: `poki-setup login <email> --keep-password`. It asks me for the password and then for the six-digit code Apple sends to my devices or by text. When I say it worked, run `next` again. If you can only run commands yourself: on macOS have me store the password with `security add-generic-password -U -s nz.zheha.poki.setup -a agent-password -w`, then run `security find-generic-password -s nz.zheha.poki.setup -a agent-password -w | poki-setup login <email> --password-stdin --keep-password --json` and afterwards `security delete-generic-password -s nz.zheha.poki.setup -a agent-password`. If that exits with 3, ask me for the code and run `poki-setup login --code <code> --json`. A code from Settings > [my name] > Sign-In & Security > Two-Factor Authentication > Get Verification Code also works.
4. Phone steps need me: plug the phone in with a cable, unlock it, tap Trust and enter the passcode; turn on Developer Mode in Settings > Privacy & Security > Developer Mode when Qeno Setup asks, then restart and tap Turn On; with a free Apple Account, trust the developer in Settings > General > VPN & Device Management; open Poki once; when Poki first opens it asks for Automation Mode, so tap Continue and enter the passcode on iOS's screen (if I cancel, Poki asks again only after I turn it on again). Tell me each one when `next` or a command asks for it, one at a time, in plain words.
5. Do not drive or tap the phone yourself, do not change Apple Account settings, and do not deploy the relay to Cloudflare unless I ask.
6. If something fails twice, run `poki-setup support --json` and show me where the bundle was saved, and what failed.

When `next` reports `ready`, tell me Poki is installed, how many days it is signed for, and that Qeno Setup renews it by itself while this computer is on.
